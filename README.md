# 하루 표정 타이머 (timer_ver001)

시간이 줄어들수록 연구실 조수 **하루**가 점점 당황하는 타이머입니다.

- 남은 시간은 7세그먼트 숫자와 20칸 배터리 게이지로 표시 (게이지 = 남은 시간 비율)
- 잔량 50% 이하 주황, 20% 이하 빨강 깜빡임
- 하루 표정 29장 전부를 여유 → 당황 순으로 배치, 30초마다 남은 시간 비율에 맞춰 표정 변경, 종료 시 충격
- 빠른 설정(1~60분), 분·초 직접 입력, +1분, 일시정지, 초기화, 전체 화면, 종료 알림음
- 단축키: Space 시작·정지, R 초기화
