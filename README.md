# 하루 표정 타이머 (timer_ver001)

연구실 조수 **하루**의 표정이 30초마다 바뀌는 타이머입니다.

- 타이머 / 스톱워치 모드
- 빠른 설정(1~60분), 분·초 직접 입력, +1분, 일시정지, 초기화, 전체 화면
- 표정 순서: 차례대로 / 무작위 (하루 표정 29장)
- 종료 시 응원 → 뿌듯함 표정과 알림음
- 단축키: Space 시작·정지, R 초기화
