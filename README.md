# Haru & Intern's TIMER (timer_ver001)

시간이 줄어들수록 연구실 조수 **하루**와 인턴 **시아**·**모아**가 점점 당황하는 타이머입니다. 위쪽 버튼으로 캐릭터를 고릅니다.

- 남은 시간은 7세그먼트 숫자와 20칸 배터리 게이지로 표시 (게이지 = 남은 시간 비율)
- 잔량 50% 이하 주황, 20% 이하 빨강 깜빡임
- 캐릭터별 표정 29장 전부를 여유 → 당황 순으로 배치, 30초마다 남은 시간 비율에 맞춰 표정 변경, 종료 시 충격
- 빠른 설정(1~60분), 분·초 직접 입력, +1분, 일시정지, 초기화, 전체 화면
- 종료 알림음 7가지 중 선택(픽셀 팡파레·레벨 업·학교 차임벨·탁상 벨·삐삐 알람·경보 사이렌·끄기), 미리 듣기
- 단축키: Space 시작·정지, R 초기화

캐릭터 그림 출처: [초파리 연구실 표정 라이브러리](https://adminmrobo.github.io/fruitfly-lab-expressions/)
